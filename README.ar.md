# ليندو CMS — منصة تطبيقات قابلة لإعادة الاستخدام (العربية)

> متوفر أيضًا بـ [English](README.en.md) · [Indonesia](README.id.md)

**ليندو CMS** منصة إدارة محتوى وتطبيقات (زفاف/مواعدة، نقاط البيع، ERP، فندق، تعليم، سوق، SaaS) مبنية على **Laravel 13 + PHP 8.3 + Tabler**. النواة **لا تحتوي أبدًا** على منطق تطبيقي خاص — كل الأعمال في `modules/`.

## الميزات
### 1. النواة
إقلاع، إعدادات (`config/lindu.php`)، مزودات، أحداث، وظائف/طوابير، مجدول، كاش، سجل تدقيق، تخزين، لغات (id/en)، فحص صحة، نسخ احتياطي، استيراد/تصدير.

### 2. المصادقة والأمان
دخول، تسجيل، خروج، استعادة كلمة المرور، تذكرني، تحديد معدل، سجل دخول، تفعيل الحساب، **تحقق بخطوتين TOTP** مع رموز احتياطية، إدارة الجلسات/الأجهزة، OAuth جاهز، رموز Sanctum.

### 3. الصلاحيات RBAC
مستخدمون، أدوار، أذونات (127)، مجموعات، سياسات، وسيط `permission`.

### 4. القوائم
من قاعدة البيانات، تداخل غير محدود، أيقونة/مسار/رابط/صلاحية/شارة/ترتيب/ظهور، لوحة إدارة.

### 5-7. الوحدات والإضافات والقوالب
دورة حياة: اكتشاف→تثبيت→تفعيل→تعطيل→حذف، 15 وحدة، 3 إضافات (hooks/filters)، قالبان، CSS/JS مخصص.

### 8-9. المحتوى والسيو
صفحات (مسودة/منشور/مجدول/مراجعات/منشئ)، مدونة، وسائط **بالطابور** (مصغرات + WebP + AVIF)، سيو (OG/Twitter/sitemap/schema).

### 10-14. البناة وسير العمل
**منشئ صفحات بالسحب** (21 مكوّنًا، جوال/لوحي/سطح مكتب، تراجع، معاينة)، منشئ نماذج (19 حقلًا)، منشئ بيانات (جداول `cb_*` + CRUD/API)، سير عمل (محفز→شرط→إجراء).

### 15-17. API و Webhooks
**REST v1+v2** مع Bearer وترقيم وبحث، v2 يدعم `?include=&fields=`، ملف OpenAPI، Webhooks بتوقيع HMAC وإعادة محاولة.

### 18-27. المستأجرون و SaaS
مستأجرون+نطاقات+حصص، خطط/اشتراكات، علامة بيضاء، تراخيص، تحديثات، نسخ احتياطي، تدقيق.

### التطبيقات والدفع و PWA
متجر، نقاط بيع، فندق، تعليم، CRM، سوق، **Jodohku**؛ بوابات Xendit/iPaymu/Tripay/Stripe؛ تطبيق ويب تقدمي PWA.

### إضافات (v1.3–v1.5)
QR من الخادم، مراقبة الطوابير، فهرسة البحث، رفع S3 المباشر، فحص الصحة `lindu:doctor`، إدارة Tabler كاملة.

## التثبيت
```sh
composer install; cp .env.example .env; php artisan key:generate
php artisan migrate --seed; php artisan serve
```
الدخول: `admin@lindu.local / password123`
