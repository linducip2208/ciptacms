# Modules

Lifecycle: discover → install → activate → deactivate → update → uninstall.

Each module: `module.json`, `routes.php`, `routes-api.php`, `views/`, `lang/`, `database/migrations/`.

Registry table `modules`. Manage at `/admin/modules`.

Core modules: pages, blog, media, seo, forms. Business: ecommerce, pos, hotel, lms, crm, erp, marketplace, jodohku, tenants, api.
